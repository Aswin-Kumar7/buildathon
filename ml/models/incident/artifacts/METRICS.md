# METRICS — card-testing risk model

Generated by `make eval`. Not hand-edited. Every number here is read from `metrics.json`, which is
deterministic from a fixed seed, so this file is a stable record rather than a snapshot of one run.

**These labels are synthetic, not real-world outcomes.** Synthetic scenario corpus, not real-world labels. Every row is an entity from a seeded scenario the project authored; the label is the scenario's ground truth, not a confirmed chargeback. Scores measure the deployed model on a held-out grouped split of this corpus. The path to real labels is the merchant's own confirmed incidents — see the retraining design.

## Headline

The deployed model, on a held-out grouped split (1325 entities,
280 abuse), at the cost-optimal block threshold **0.080**:

- PR-AUC **0.940 (0.919–0.957)** (no-skill floor 0.211)
- Precision 0.721 (0.672–0.767), Recall 0.971 (0.952–0.989), F1 0.828 (0.793–0.859)
- ROC-AUC 0.981, Brier 0.044
- Operating point: false-decline 0.100, block-eligible 0.285,
  review band 0.029 at a 0.030 analyst budget
